# Backend API Server

A simple backend API project built using Node.js and Express.js. This project demonstrates how to create REST API endpoints, handle JSON data, enable CORS, and perform basic CRUD operations.

## Features

- Node.js and Express.js backend
- REST API structure
- CORS enabled
- JSON request handling
- GET, POST, DELETE API examples
- Easy to connect with React frontend

## Tech Stack

- Node.js
- Express.js
- CORS
- JavaScript

Live:https://backendapi-khaki.vercel.app/

## Learning Outcome

Through this project, I learned how to:

Create a backend server using Express.js
Build REST API endpoints
Send and receive JSON data
Use CORS to connect frontend and backend
Test API routes locally
Prepare backend for deployment
